# EGET

EGET is a modern mobile vehicle marketplace designed for Ghana.

The app allows users to discover vehicles for sale, search for vehicles, view vehicle details, save favourites, and eventually sell/list their own vehicles.

## Project

This repository contains the EGET mobile application.

### Technology

- .NET MAUI
- C#
- XAML
- Visual Studio 2026
- Android first
- iOS planned later

### Branding

EGET uses a premium Bumblebee-inspired visual identity:

- Black
- Bumblebee Yellow
- White where appropriate

The design should remain clean, modern, and easy to use.

## Current Stage

The mobile application is currently in the initial UI and architecture stage.

The current home screen includes:

- EGET branding
- Vehicle search
- Buy a Car
- Sell a Car
- Latest Vehicles
- Vehicle listing cards
